# คู่มือการใช้งานระบบคลังงานวิจัยดิจิทัล มหาวิทยาลัยราชภัฏสุรินทร์
## (SRRU Digital Research Repository & Intelligent Recommendation System User Manual)

---

## 1. บทนำและภาพรวมของระบบ (System Overview)
ระบบคลังงานวิจัยดิจิทัล มหาวิทยาลัยราชภัฏสุรินทร์ เป็นเว็บแอปพลิเคชันจัดการความรู้วิชาการ (Academic Knowledge Management) ที่รวบรวมวิทยานิพนธ์ระดับบัณฑิตศึกษา (ป.โท/ป.เอก), โครงงานวิจัยปริญญาตรี (Senior Project), การศึกษาค้นคว้าอิสระ (IS), และบทความวิจัยของทั้ง 7 คณะในมหาวิทยาลัยราชภัฏสุรินทร์ พร้อมติดตั้งระบบปัญญาประดิษฐ์ (AI) ขั้นสูงเพื่อสนับสนุนการศึกษาและการทำวิจัย

### 🌟 ฟังก์ชันเด่นของระบบ:
1. **Dense Semantic Vector Search**: สืบค้นงานวิจัยด้วยความหมายและภาษาธรรมชาติภาษาไทย
2. **AI Document Q&A (RAG on PDF)**: สนทนาถาม-ตอบเจาะลึกสาระสำคัญจากเอกสาร PDF พร้อมระบุเลขหน้าอ้างอิง
3. **Research Knowledge Graph**: ผังเครือข่ายความรู้วิชาการ 2D/3D Interactive สำรวจความเชื่อมโยงข้ามศาสตร์
4. **Real-time AI Redundancy Radar**: ตรวจสอบความซ้ำซ้อนของหัวข้อวิจัยแบบเรียลไทม์พร้อมพิมพ์ใบรับรองความแปลกใหม่ (Certificate)
5. **Literature Review Matrix Generator**: ตารางสังเคราะห์วรรณกรรมเปรียบเทียบสำหรับเขียนบทที่ 2
6. **Thesis & Project Topic Proposal Generator**: AI ช่วยคิดและสังเคราะห์ 3 โครงร่างวิจัยตามโจทย์ที่สนใจ

## 2. คู่มือสำหรับนักศึกษา (Student Manual)

### 2.1 การเข้าสู่ระบบและการสลับบัญชี
1. เข้าสู่เว็บไซต์ที่ `http://localhost:5173`
2. คลิกปุ่ม **"เข้าสู่ระบบ"** ที่แถบเมนูด้านบน
3. ใช้อีเมลนักศึกษา `@student.srru.ac.th` หรือกดปุ่มด่วน **"นักศึกษา (student1)"** เพื่อทดสอบระบบ

### 2.2 การสืบค้นและอ่านเอกสารวิจัย
1. ไปที่เมนู **"สืบค้นงานวิจัย"** หรือพิมพ์คำค้นหาที่หน้าแรก
2. เลือกโหมดการค้นหา:
   - **Semantic AI Search**: ค้นหาด้วยความหมายเชิงลึก (เช่น พิมพ์ *"ตรวจจับโรคใบข้าว"* ระบบจะค้นพบงานวิจัยที่ใช้ *"การเรียนรู้เชิงลึก และ CNN"* ด้วย)
   - **Standard Keyword**: ค้นหาตามคำสำคัญตรงตัว
3. กรองผลลัพธ์ตามคณะ, สาขาวิชา, ปี พ.ศ., หรือประเภทเอกสาร
4. คลิกการ์ดผลงานวิจัยเพื่อเข้าสู่หน้ารายละเอียด
5. ในหน้ารายละเอียด:
   - สลับแท็บ **"📄 อ่านเอกสารฉบับเต็ม (PDF Reader)"** เพื่ออ่านไฟล์ PDF
   - สลับแท็บ **"💬 AI Chat with PDF (RAG)"** เพื่อพิมพ์ถามคำถาม เช่น *"อัลกอริทึมที่ใช้คืออะไร"*, *"ผลการทดลอง F1-score เท่าไร"*
   - กดปุ่ม **"📜 ใบรับรองความซ้ำซ้อน"** เพื่อเปิดดู Certificate
   - กดปุ่ม **"การอ้างอิง & ส่งออกไฟล์ (Citation)"** เพื่อคัดลอกรูปแบบ APA 7th, IEEE หรือดาวน์โหลดไฟล์ `.RIS` (EndNote/Zotero) และ `.BIB` (BibTeX)

### 2.3 การใช้ AI คิดหัวข้อวิจัย (Topic Generator)
1. ไปที่เมนู **"💡 คิดหัวข้อวิจัย"**
2. เลือกคณะและระดับการศึกษา (ปริญญาตรี หรือ ปริญญาโท/เอก)
3. ระบุคำสำคัญหรือความสนใจ เช่น *"ข้าวหอมมะลิ AI"*, *"ผ้าไหมสุรินทร์"*
4. กด **"สร้างหัวข้อวิจัยด้วย AI"** ระบบจะวิเคราะห์และเสนอโครงร่างวิจัย 3 ข้อ พร้อมวัตถุประสงค์ เทคโนโลยีที่แนะนำ และคะแนนความแปลกใหม่ (Originality Score)
5. กดปุ่ม **"นำหัวข้อนี้ไปส่งผลงาน"** เพื่อส่งต่อข้อมูลไปยังฟอร์มส่งงานทันที

### 2.4 การส่งผลงานวิจัย (Submit Research)
1. คลิกปุ่ม **"+ ส่งผลงานวิจัย"**
2. เลือกประเภทเอกสาร (วิทยานิพนธ์, โปรเจกต์จบ, IS, หรือบทความวิจัย)
3. กรอกชื่อเรื่องภาษาไทย, ภาษาอังกฤษ, บทคัดย่อ, คำสำคัญ, และเลือกอาจารย์ที่ปรึกษา
4. สังเกตแถบ **"AI Redundancy Check Radar"** ที่จะคำนวณเปอร์เซ็นต์ความซ้ำซ้อนกับงานวิจัยในคลังแบบเรียลไทม์
5. แนบไฟล์เอกสาร `.pdf` และกดยืนยันการส่งผลงาน

## 3. คู่มือสำหรับอาจารย์และผู้ตรวจงาน (Teacher Manual)

### 3.1 การเข้าสู่โหมดอาจารย์
1. คลิกที่รูปโปรไฟล์มุมขวาบน
2. เลือกเปลี่ยนบทบาทเป็น **"อาจารย์ (TEACHER)"**

### 3.2 การตรวจและอนุมัติผลงานวิจัย
1. ไปที่เมนู **"ตรวจอนุมัติงานวิจัย"**
2. ตารางจะแสดงรายการผลงานวิจัยที่นักศึกษาส่งเข้ามาในสถานะ **"รอตรวจสอบ (PENDING)"**
3. คลิกปุ่ม **"ตรวจงาน & คอมเมนต์ PDF"**
4. ระบบจะเปิดตัวอ่าน PDF Reader พร้อมฟังก์ชัน **Academic Review & PDF Annotations**:
   - สามารถเลือกข้อความใน PDF เพื่อใส่ไฮไลต์และข้อคิดเห็น (Reviewer Comment)
5. เลือกผลการประเมิน:
   - **"อนุมัติ (Approve)"**: ผลงานจะถูกเผยแพร่สู่คลังงานวิจัยสาธารณะทันที
   - **"ส่งกลับแก้ไข (Reject)"**: ระบุข้อคิดเห็นเพื่อให้นักศึกษานำไปปรับปรุง

## 4. คู่มือสำหรับผู้ดูแลระบบและผู้บริหาร (Admin Manual)

### 4.1 การดูสถิติและแนวโน้มงานวิจัย (Analytics Dashboard)
1. เข้าสู่ระบบด้วยบทบาท **"ผู้ดูแลระบบ (ADMIN)"**
2. ไปที่เมนู **"แดชบอร์ดสถิติ"**
3. ตรวจสอบข้อมูลสถิติสำคัญ:
   - สรุปตัวชี้วัด KPI 4 ด้าน (จำนวนงานวิจัย, สถิติการเข้าชม, การดาวน์โหลด, ผู้ใช้งาน)
   - สัดส่วนงานวิจัยรายคณะ (Faculty Distribution)
   - คลัสเตอร์งานวิจัยและแนวโน้มการเติบโต (Research Trend Forecasting)
   - คำค้นหายอดนิยม (Trending Search Keywords)
4. กดปุ่ม **"ส่งออกรายงาน (Export CSV)"** เพื่อดาวน์โหลดข้อมูลสรุปในรูปแบบสเปรดชีต Excel/CSV

### 4.2 การจัดการสิทธิ์ผู้ใช้งาน (RBAC Management)
1. ในหน้าแดชบอร์ด เลื่อนลงมาที่ตาราง **"การจัดการสิทธิ์ผู้ใช้งาน (RBAC Management)"**
2. สามารถปรับเปลี่ยนบทบาทผู้ใช้ระหว่าง `STUDENT`, `TEACHER`, และ `ADMIN` ได้แบบเรียลไทม์

- กดปุ่มไอคอน **☀️ / 🌙** ที่แถบเมนูด้านบนเพื่อสลับระหว่าง **Light Mode (โหมดสว่าง)** และ **Dark Mode (โหมดมืด)**
